Controls & trust

Reward controls for a real beta.

SOLARA uses wallet-gated validation sessions, live reward tracking, and admin controls for a manageable beta network.

Wallet sessions

one active GPU

Each wallet can run one active validation session. Starting a new plan closes the old session after rewards are accrued.

Withdraw threshold

10 SOLR minimum

Withdrawals are available once claimable rewards reach the configured threshold, keeping tiny withdrawals out of the queue.

Admin controls

pause · blacklist · approve

The admin wallet can pause rewards, manage rates, approve withdrawal flow, and block abusive wallets from starting new sessions.
