How SOLARA validation works

Simple rewards, controlled payouts.

1. Select hardware

Each GPU plan has a fixed SOLR-per-minute rate. SOLARA records the selected plan when the session starts.

2. Accrue rewards

The server updates your wallet balance from elapsed session time, daily limits, and the current rate table.

3. Request payout

Eligible balances can be requested once the minimum threshold and cooldown are clear. Admin approval controls outgoing SOLR payouts.
